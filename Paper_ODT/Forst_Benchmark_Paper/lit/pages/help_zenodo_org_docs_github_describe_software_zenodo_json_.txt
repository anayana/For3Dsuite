Zenodo JSON file
A
.zenodo.json
file can be added to your GitHub repository to describe the software after it is preserved in Zenodo.
Note:
If your repository contains both a
.zenodo.json
and a
CITATION.cff
file, Zenodo will
only
use the
.zenodo.json
metadata. The
CITATION.cff
will be completely ignored for the GitHub release archiving.
Why use .zenodo.json?
The
.zenodo.json
format supports Zenodo-specific metadata that
CITATION.cff
does not yet support, such as:
Funding information
via the
grants
field
Zenodo communities
via the
communities
field
Other Zenodo-specific fields like
access_right
,
related_identifiers
, and contributor roles
If you don't need these Zenodo-specific features, a
CITATION.cff
file alone is sufficient.
Create a .zenodo.json file
1
Open your repository on GitHub
2
Add a new file
3
Name it
.zenodo.json
4
Commit the file
6
Archive the release
