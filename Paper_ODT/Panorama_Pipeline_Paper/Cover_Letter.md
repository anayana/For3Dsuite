To the Editors of *Computers & Geosciences*

Dear Editors,

please consider the manuscript **"An open, containerized pipeline turning
multi-image captures — from consumer 360° cameras to terrestrial laser scanners —
into web-navigable 3D scenes"** for publication as an Application Article in
*Computers & Geosciences*.

The manuscript presents For3Dsuite, an open-source (GPL-3.0-or-later),
containerized processing chain with a browser-based interface that turns
multi-image captures into walkable web scenes. It handles two input classes that
are usually treated separately: captures without known pose, which are stitched,
and the RGB images of terrestrial laser scanners, whose poses are stored in the
E57 file and which are reprojected directly. In a ground-truth evaluation on
eleven CC0 reference panoramas, the pose-based branch outperforms stitching on
every measure, yields a usable panorama for all scenes, and is about seven times
faster; a reference-free measurement on real captures quantifies how strongly
parallax degrades stitching.

The work fits the scope of the journal as open software for processing
geospatial sensor data (terrestrial laser scanning and panoramic imagery). It is
fully reproducible: the source code is in a public, documented GitHub repository
and archived on Zenodo (details in the section "Code availability"), and all data
used are third-party open data.

The manuscript has not been published and is not under consideration elsewhere.
