# For3Dsuite: eigene 360°-Aufnahmen zu begehbaren Szenen

Studio (Upload, Verarbeitung, Marker): **/admin/** · Galerie: **/**

- Fertiges 360°-Panorama (2:1), Fisheye-Bildsatz oder E57-Laserscan hochladen
- Die Verarbeitung erkennt die Art der Aufnahme selbst (Übernahme, Stitching, Reprojektion)
- Marker per Klick ins Panorama setzen und beschriften

Quellcode, Anleitung und Paper: https://github.com/anayana/For3Dsuite (GPL-3.0-or-later)

Hinweis: Diese Instanz ist eine Demo. Alle hier hochgeladenen Szenen sind für alle
Besucher sichtbar und können bei einem Neustart verloren gehen. Für dauerhafte und
eigene Daten die Software selbst betreiben (Docker, siehe `platform/README.md`).
